# 蜜蜂 Track ID 修正器

由我们团队自主开发并开源的蜜蜂标注与人工复核软件，采用 [MIT 许可证](./LICENSE)。

用于检查和修正 X-AnyLabeling / LabelMe JSON 中的蜜蜂 Track ID，并支持室内/室外轨迹逐条复查、原视频同步对照、检测框编辑、MOT 导出、自动备份与撤销。

当前版本：`v1.46`

## 获取软件

从 GitHub Releases 下载 `Bee-TrackID-Corrector-v1.46-Windows.zip`，完整解压后双击 `蜜蜂TrackID修正器_v1.46.exe`。也可以按下节从源码启动。

原 `v1.44` 内部便携包包含比赛原视频和演示标注，已保留为维护者可见的草稿，不作为公开软件下载包。运行时请使用自行持有使用权限的视频、图像与标注。

## 从源码运行

```powershell
pip install -r requirements.txt
python app.py
```

也可以双击 `run_trackid_corrector.bat`。

如需同步查看原视频，请在程序目录放置 `原视频` 文件夹，或在软件中点击“原视频目录”选择实际路径。

## 数据目录

软件可打开标注员总目录，也可直接打开一个区段目录：

```text
标注员_XX/
├─ A-5-1_区段_01/
│  ├─ A-5-1_frame_000100.jpg
│  ├─ A-5-1_frame_000100.json
│  └─ ...
└─ B-5-1_区段_01/
   └─ ...
```

图片与 JSON 需要同名；JSON 中的蜜蜂矩形框需要带 Track ID。

如果当前模式没有待审核项目，软件仍会显示图片，并说明是没有有效 Track ID、没有后续新 ID，还是已经全部审核完成。

## 主要模式

### 新 ID 纠正

- 查看新出现的 Track ID 及候选旧 ID；
- `C`：把新 ID 合并到选中的旧 ID；
- `V`：确认为真正的新目标；
- `P`：打开局部运动和原视频对比；
- `G`：打开全局鸟瞰。

### 室内/室外轨迹复查

- 逐条检查名称以 `A-` 开头的室外 Track ID 和以 `B-` 开头的室内 Track ID；
- `J / K`：上一条 / 下一条轨迹；
- `Space`：标记当前轨迹通过；
- `M`：标记当前轨迹有问题。

## 局部运动窗口快捷键

| 快捷键 | 功能 |
| --- | --- |
| `A / S` | 上一张 / 下一张抽帧 |
| `D / F` | 上一帧 / 下一帧原视频 |
| `H` | 隐藏 / 恢复检测框 |
| `B` | 隐藏 / 恢复轨迹 |
| `Z` | 显示全部 ID / 当前 ID |
| `X` | 回到目标首次出现位置 |
| `R` | 开启 / 退出画框模式 |
| `Ctrl+Z` | 撤销 |

## 团队工具与数据飞轮

本工具用于新旧 ID 关联、重复身份合并、轨迹复查和 MOT 导出；头尾关键点补标与姿态复核可配合团队开发的 [蜜蜂关键点标注器](https://github.com/CyberMagician01/Bee-Keypoint-Annotator)。复核者可将框、关键点与身份问题分别修正，再将结果交回数据飞轮汇总。
